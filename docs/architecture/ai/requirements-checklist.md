### 1.1 已记录但暂不实现的工作流设想

```text
输入
  调研目的
  兴趣方向
    ↓
收集与整理资料
  当前已有资料
  后续更新资料
  相关数据
    ↓
生成与目的、兴趣方向匹配的介绍
    ↓
未来可选：生成 PPT
```

仍需确认资料来源、更新时间要求、引用方式、介绍的结构和验收标准。当前 Mastra 验证
端点不会接受这些业务字段，也不会模拟资料检索或 PPT 生成。

## 8. 开发启动条件

基本模型连通性验证已经完成。满足以下条件后，才进入 Mastra **业务试点**：

1. 明确一个首期用户场景和验收示例。
2. 明确该场景需要 Agent 还是确定性 Workflow。
3. 明确数据 Scope 和最小权限。
4. 明确前端是否需要新的事件类型。
5. 明确哪些数据允许持久化。
6. 确认验证只在独立分支进行，且可以回退到现有 DeepSeek 链路。
